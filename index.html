First 90 Days — Your Framework

You built this answer in the interview. Now make it real.

DAY 1–30
Listen and map
Sit with teams. Review live CDEs. Read existing BEPs and EIRs. Map who is digital-resistant vs early-adopter. Don't propose changes yet — understand the system first.
DAY 31–60
Identify the highest-leverage fix
One process change with the clearest operational ROI. Present it to the Ops Manager with the problem, proposed fix, and how you'll measure it. One thing, done properly.
DAY 61–90
Prove it works — then build on it
Implement the fix. Track the result. Use that credibility as the foundation for a broader delivery framework. You don't fix culture by writing a better standard — you make the right behaviour easier than the wrong one.
