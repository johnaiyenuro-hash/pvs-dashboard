1. Situation (The Problem & Operational Context)
  • The Strategic Need: Managing a multi-year career trajectory (DDM onboarding → Solutions Architect dual track, Spain DNV mobility, technical study queues, and habit momentum) required a unified, high-signal dashboard.
  • The Manual Friction:
    • Early iterations required manual HTML copy-pasting into Google Sites or GitHub's browser editor with every task or habit streak increment.
    • Sandboxed Google Sites iframes stripped raw HTML script executions, while cross-origin security rules (X-Frame-Options) prevented embedding raw GitHub repositories directly.
    • Managing separate repositories for individual trackers created context switching and maintenance overhead.
2. Task (The Engineering Objective)
  • Design an Automated, Decoupled Architecture: Build an automated personal operating system (PVS) with zero friction between local terminal activity, version-controlled cloud storage, and public-facing visual dashboards.
  • Constraints & Principles:
    • Zero Code-Rot: Strict preservation of design tokens, CSS variables (--accent, --surface), and DOM structure.
    • State Continuity: Browser localStorage persistence across embedded iframes using an explicit namespace (habakuk_os_) to prevent key collisions.
    • Terminal-First Execution: Eliminate browser logins and manual file management through autonomous CLI execution.
3. Action (The Architectural Implementation)

  • Autonomous CLI Automation via Antigravity: Integrated Antigravity CLI (agy --yolo) with Windows PowerShell profile scripting ($PROFILE), enabling plain-English terminal commands to execute file parsing, streak calculations, Git staging, and remote pushes autonomously.
